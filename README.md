# Rajesh Bhawan — Professional IT Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `Rajesh-Professional-Portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Customize
- Edit profile text and project descriptions in `index.html`.
- Update colors and layout in `style.css`.
- Replace `assets/avatar.svg` with your own image if you prefer.
- Replace `assets/Rajesh_Bhawan_CV.pdf` with your updated CV when you have one.

## Publish
Create a public GitHub repository and upload the complete contents of this folder. On Vercel or Netlify, import that GitHub repository. For a plain HTML website, the publish/root directory is the project root; no build command is needed.

## Notes
The portfolio uses only the details supplied by Rajesh. Project summaries are introductory descriptions and should be updated with actual screenshots, repository links, implementation details and outcomes as the projects are completed. No certificates or employment history have been invented.
